# Generador de Frases - League of Legends 🎮

Una aplicació Android senzilla i intuïtiva desenvolupada en **Kotlin** amb interfície en **XML**. L'aplicació genera de forma aleatòria frases icòniques de campions de *League of Legends* acompanyades dels seus corresponents emojis.

---

## 🚀 Característiques

- **Frases de League of Legends**: Més de 20 frases de campions icònics com Rammus, Garen, Jinx, Teemo, Yasuo, etc.
- **Emojis representatius**: Cada frase inclou el nom del personatge i un emoji personalitzat.
- **Interfície senzilla i neta**: Dissenyat amb un `MaterialCardView` centralitzat i un únic botó per generar noves frases aleatòries sense repetir la frase anterior consecutivament.
- **Desenvolupament modern**: Fet amb Kotlin, Material 3 i layout en XML.
